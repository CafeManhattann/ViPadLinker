## 🎮 Mode 1: Merge Two Gamepads Into One

This is the headline feature. Plug in two controllers, open ViPadLinker, and turn on the merge option. ViPadLinker creates one virtual Xbox-style controller for Windows and feeds it input from both of your physical gamepads.

In practice, that means:

- Player one presses A, the game sees A.
- Player two presses A, the game also sees A.
- Both players can move, jump, and shoot at the same time through the same virtual player.

This is ideal for couch co-op where a game offers only one player slot but you still want to play together. One person handles movement while the other handles action, or you both grab the controls and laugh through the chaos. It also works nicely for handing a controller back and forth without unplugging anything.

Before you enable merging, make sure both controllers are connected and awake. Press a button on each one so Windows notices them. Then flip the merge switch and start your game. If the game was already running, close it and open it again so it picks up the new virtual controller.

## 🎯 Mode 2: Hold XInput Slots

Windows assigns player numbers to controllers in the order it discovers them, and that order can change when you unplug something or wake a controller from sleep. In a four-player game, that means your controller might suddenly become player three instead of player one.

ViPadLinker lets you pin controllers to slots. Choose the controller you care about, choose the player number you want it to occupy, and ViPadLinker keeps that slot held. Your controller stays in the right seat, and the game keeps showing your name and your save profile in the right place. This is especially helpful for racing games, fighting games, and any title that remembers progress per player slot.

## 🧰 Troubleshooting

**My controller is not listed.** Press a button on the controller so it wakes up, then unplug and reconnect it. For Bluetooth controllers, remove the device in Windows settings and pair it again.

**The game sees no controller.** Start ViPadLinker before the game. If the game was already open when you turned on merging, restart it.

**The wrong player number appears.** Use the slot holding feature to pin your controller to the number you want, then restart the game.

**Buttons feel swapped.** Open the remapping screen and use the reset option to return to the default layout, then change only the buttons you actually need.

**Two controllers fight for control in merge mode.** That is expected — in merge mode both controllers drive the same virtual player, so any input from either one is combined.
